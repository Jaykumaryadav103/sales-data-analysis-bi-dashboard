# Sales Data Analysis & Business Intelligence Dashboard

**Status: In progress**

## Overview
This portfolio project will explore synthetic retail sales data and present useful business metrics through SQL, Python/Pandas, and Power BI.

## Dataset
The practice data will be synthetic and will not contain real customer information. Planned tables:

- `orders` - order date, customer, region, channel, and status
- `order_items` - product, quantity, price, discount, and refund
- `products` - product name and category
- `customers` - customer segment and signup date

## Business Questions
- How does net revenue change by month?
- Which product categories contribute the most revenue?
- How do orders and average order value vary by channel or region?
- Where are discounts and refunds concentrated?

## Planned Workflow
1. Generate and validate the sample data.
2. Use SQL joins, filters, and aggregations to answer the business questions.
3. Use Pandas for data checks and exploratory analysis.
4. Build a Power BI dashboard with KPI cards, trend charts, and filters.
5. Document metric definitions, findings, and limitations.

## Data Quality Checks
The analysis will check for duplicate IDs, missing values, unmatched keys, invalid dates, and unusual prices, discounts, or refunds.

## Findings
Findings will be added after the analysis has been implemented and run. Any example numbers in the project guide are illustrative only and are not results from this repository.

## Tools
SQL, Python, Pandas, Power BI

## Project Structure
The repository will include the data generator, SQL queries, analysis notebook or scripts, dashboard, and documentation as they are completed.
